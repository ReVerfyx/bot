# 🔧 Настройка с нуля

Пошагово: где взять каждое значение, куда его вписать и как проверить, что всё работает.
Порядок важен — **шаг 1 обязателен до первого запуска бота**.

---

## Шаг 1. Приватный репозиторий ✅

Уже сделано — репозиторий приватный. Так и должно быть: бот хранит заказы, адреса
доставки и промокоды в GitHub Issues, в публичном репозитории их прочитал бы кто угодно.

Если когда-нибудь понадобится перепроверить: `Settings → General → Danger Zone`,
там должно быть предложение **Make public** (а не *Make private*).

## Шаг 2. `BOT_TOKEN` — токен бота

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`
2. Придумай имя (видит клиент) и username (обязан заканчиваться на `bot`)
3. BotFather пришлёт строку вида `8123456789:AAH-abcdefgh...` — это и есть токен

Токен = полный доступ к боту. Утёк — сразу `/revoke` у BotFather.

Заодно там же можно оформить бота (см. [готовые тексты](#тексты-для-botfather) внизу):
`/setdescription`, `/setabouttext`, `/setuserpic`.

**Команды в меню бота не добавляй** — `/admin` не должна светиться в подсказках Telegram.

## Шаг 4. `ADMIN_CHAT_ID` — куда падают заявки *(необязательно)*

Если не задавать — все заявки приходят тебе в личку от бота. Этого достаточно
и это самый скрытный вариант.

Если хочешь общую группу для операторов:

1. Создай группу, добавь туда своего бота и выдай ему права администратора
2. Напиши в группу любое сообщение
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
4. Найди `"chat":{"id":-1001234567890` — это и есть ID (с минусом!)

⚠️ В группе тебя видят все её участники. Для максимальной скрытности оставь поле пустым.

---

## Шаг 5. `ADMIN_SECRET` — кодовое слово входа в админку *(необязательно)*

Любая строка, например `otkroysya-2026`. Отправляешь её боту в личку — открывается
панель, а само сообщение бот удаляет. Работает только для ID из `ADMIN_IDS`:
чужой человек, угадав слово, ничего не получит.

Альтернативный вход — команда `/admin` (бот тоже стирает её из чата).

---

## Шаг 6. `CRYPTOBOT_TOKEN` — приём криптовалюты *(необязательно)*

Без него останется только ручной перевод на кошелёк — это рабочая схема.

1. Открой [@CryptoBot](https://t.me/CryptoBot) → **Crypto Pay** → **Create App**
2. Выбери приложение → **API Token** → скопируй строку вида `12345:AAxxxxx`
3. Там же **Payments → Enable** и включи нужные монеты

Что даёт: счёт выставляется в рублях, клиент платит криптой, бот сам проверяет оплату
кнопкой «Проверить оплату». Выдачу всё равно подтверждаешь ты.

---

## Шаг 7. `GH_PAT` — мгновенный самоперезапуск *(рекомендуется)*

Без него бот перезапускается только по cron (раз в 6 часов) — возможен простой
в несколько минут между сменами. С ним новая смена стартует сразу.

1. `https://github.com/settings/tokens` → **Tokens (classic)** → **Generate new token (classic)**
2. Note: `bot-restart`, Expiration: `No expiration`
3. Скоупы: ✅ **`repo`** и ✅ **`workflow`**
4. **Generate token** → скопируй `ghp_...` (показывается один раз)

`GH_STORE_TOKEN` создавать не нужно — для хранилища используется встроенный
`GITHUB_TOKEN`, который GitHub выдаёт воркфлоу автоматически.

## Шаг 8. Кошельки для ручной оплаты

Адреса берёшь в своём кошельке (Trust Wallet, Tonkeeper, Bybit, Telegram Wallet — любой)
кнопкой «Получить / Receive». Скопируй адрес **вместе с сетью**:

| Монета | Сеть | Как выглядит адрес |
|---|---|---|
| USDT | TRC-20 (Tron) | начинается с `T`, 34 символа |
| USDT | TON | начинается с `UQ` или `EQ` |
| BTC | Bitcoin | начинается с `bc1`, `1` или `3` |

Вписываются в `config.yml → payment.manual.wallets` вместо заглушек `TXXXX…`.
Сеть в поле `note` указывай явно — иначе клиенты будут слать в TON на TRC-20 адрес.

## Шаг 10. Настроить магазин

Правится **только `config.yml`**:

| Что | Где | Комментарий |
|---|---|---|
| Название, валюта | `brand` | |
| Контакт поддержки | `brand.support_username` | **оставь пустым**, чтобы не светить личный аккаунт — клиентов отправит в раздел «Поддержка» внутри бота |
| Ссылки на каналы | `brand.channel_url` / `backup_url` | основной канал и переходник, уже заполнены |
| Цены и сроки | `scooters.items[].price / duration_days` | сейчас у всех тестовые 2000 ₽ |
| Текст после активации | `scooters.items[].instructions` | приходит клиенту после номера самоката или скриншота |
| Сетка комиссии Сплита | `split.tiers` | до 60к → 2000 ₽, до 150к → 5000 ₽ |
| Лимит цены товара | `split.max_price` | выше — заявка отклоняется |
| Кошельки | `payment.manual.wallets` | из шага 8 |
| Все реплики бота | `texts` | 73 текста |
| Эмодзи и стикеры | `decor` | `file_id` стикера даёт [@RawDataBot](https://t.me/RawDataBot). Бери **бесплатные** паки — премиум-стикеры бот отправить не сможет |

### Премиум-эмодзи и цветные кнопки (Bot API 9.4)

**Цветные кнопки работают сразу, ничего не требуют.** Акценты уже расставлены:
зелёный — шаг вперёд по заказу («Оформить заказ», «Я оплатил», «Подтвердить оплату»),
красный — разрушающее действие («Отменить», «Отклонить», «Бан»), синий — основная
навигация («Самокаты», «Проверить оплату», «Активация»). На экране максимум один
акцент каждого вида — иначе цвета перестают читаться. Выключить всё разом:
`decor.button_styles: false`.

**Премиум-эмодзи** (в текстах и иконкой на кнопке) требуют
**Telegram Premium у владельца бота** — того аккаунта, который создал бота
у BotFather. Раньше нужно было покупать юзернейм на Fragment за TON, с версии 9.4
достаточно подписки.

Сейчас они **выключены** флагом `decor.custom_emoji_enabled: false` — подписки нет.
Бот при этом полностью рабочий и цветной: обычные эмодзи, цветные кнопки, стикеры.
Появится Premium — заполни id ниже и переключи флаг в `true`, больше ничего
менять не нужно. Флаг можно оставлять выключенным с уже заполненными id.

Как получить `custom_emoji_id`:
1. Отправь премиум-эмодзи самому себе в Избранное
2. Перешли это сообщение боту [@RawDataBot](https://t.me/RawDataBot)
3. В ответе найди `entities` → `custom_emoji_id` — это длинное число

Вставь его в `decor.custom_emoji` по нужному ключу (`pay`, `check`, `scooter`…) —
эмодзи подставится и в текст сообщений, и иконкой на соответствующие кнопки.

Если Premium кончится или id окажется битым, Telegram начнёт отбивать **каждое**
сообщение. Чтобы магазин от этого не вставал, бот ловит такую ошибку, повторяет
отправку без кастомных эмодзи и дальше работает на обычных — цвета кнопок при
этом сохраняются. В логе будет строка «Telegram отказал в кастомных эмодзи».

## Шаг 11. Запуск

1. Смержи ветку `claude/telegram-yandex-go-bot-okq709` в `main`

Дальше он поднимается сам: cron каждые 6 часов + мгновенный рестарт по `GH_PAT`.

## Диагностика после запуска

Как только смена стартует, бот сам присылает админам сводку: подключено ли
хранилище на GitHub Issues, поднялся ли CryptoBot, не остались ли в кошельках
заглушки `TXXXX…`, сколько позиций в каталоге и кодов на складе. Отключается
флагом `access.notify_start: false`.

В любой момент то же самое — командой `/health` или кнопкой «🩺 Диагностика»
в админке. Если после запуска сводка не пришла — значит бот не поднялся,
смотри лог в `Actions`.

Что должно быть ✅ на боевом запуске: хранилище (GitHub Issues, а не локальные
файлы), админы, кошельки без заглушек. CryptoBot и чат заявок могут быть ❌ —
это опциональные вещи.

## Проверка боевого сценария

1. `/start` → «🛴 Самокаты» → тариф → «Оформить заказ»
2. «Перевод на кошелёк» → выбери монету → «Я оплатил» → пришли любой текст
3. Тебе в личку прилетает карточка заказа → жми **✅ Подтвердить оплату**
4. У клиента появляется меню активации → он шлёт номер самоката
5. Приходит текст из `instructions` — если да, цепочка работает целиком

Заказ параллельно виден в `Issues` с метками `order` и `status:*`.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| Бот молчит | `Actions` → последний запуск → лог. `BOT_TOKEN недействителен` — перевыпусти токен |
| `409 Conflict` в логе | Запущены два экземпляра. Останови лишний запуск в Actions — `concurrency` обычно решает это сам |
| Заявки не приходят | Проверь `ADMIN_IDS` и **напиши боту `/start` сам** — Telegram не даёт писать первым тому, кто не начинал диалог |
| Кнопка «Проверить оплату» не находит платёж | Не задан `CRYPTOBOT_TOKEN` или в приложении CryptoBot не включены Payments |
| Цена товара не определилась | Маркет отдал защищённую страницу — бот сам спросит цифру у клиента, это штатное поведение |
| Воркфлоу перестал запускаться | GitHub гасит cron в репозиториях без активности 60 дней — сделай любой коммит |
